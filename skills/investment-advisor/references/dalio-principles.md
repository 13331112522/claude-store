# Dalio 宏观周期框架 — 与价值投资的融合

> 本文件基于 Ray Dalio《原则：应对变化中的世界秩序》，提取与个人投资决策直接相关的宏观周期框架，并与段永平价值投资体系形成互补。

---

## 一、核心框架：三大周期

Dalio 认为世界经济由三大周期驱动，理解它们可以帮助投资者判断"大环境"而非"个股"。

### 1.1 货币/信贷/债务大周期

**典型路径（约 50-100 年）：**
```
硬货币 → 纸币（可兑换）→ 法币（不可兑换）→ 债务泡沫 → 债务危机 → 印钞贬值 → 新秩序
```

**关键阶段与投资含义：**

| 阶段 | 特征 | 投资含义 |
|------|------|----------|
| 硬货币期 | 货币有锚（金/银），信贷纪律强 | 债券收益可靠，现金安全 |
| 法币扩张期 | 央行主动印钞，信贷宽松 | 资产价格普涨，持有现金是劣策略 |
| 债务泡沫期 | 债务/GDP 极高，资产价格泡沫 | 减少杠杆，增加硬资产配置 |
| 危机与贬值期 | 违约、印钞、货币贬值 | 持有优质股权 > 债券 > 现金 |

**与段永平体系的交叉**：
- 段永平说"不便宜"但继续持有苹果——在法币扩张期，持有优质股权本身就是对抗货币贬值的策略
- 茅台的"越存越值钱"特性，在货币贬值期具有天然对冲价值
- 段永平"满仓主义者"——在长期法币贬值趋势下，优质股权 > 现金

### 1.2 内部秩序大周期

**典型路径（约 100 年）：**

```
新秩序建立 → 和平繁荣 → 财富差距扩大 → 泡沫 → 危机 → 革命/战争 → 新秩序
```

**六个阶段：**

1. **新秩序建立**：战后重建，机会遍地，低负债
2. **资源配置期**：制度完善，效率提升，繁荣起步
3. **和平繁荣期**：经济扩张，金融创新，泡沫萌芽
4. **泡沫与过度期**：贫富差距极化，民粹主义抬头
5. **财务困境期**：债务危机，政治极化，社会撕裂
6. **内战/革命期**：秩序崩溃，重建开始

**投资含义**：
- 判断所在国家处于哪个阶段，决定大类资产配置
- 阶段 2-3：积极投资，承担风险
- 阶段 4：开始收紧仓位，增加防御
- 阶段 5-6：极度保守，保本为主

**与段永平体系的交叉**：
- 段永平的"中国式价值投资"强调"政策敏感"——这正是对内部秩序周期的直觉性回应
- 仓位管理中的"50-60% 股票 + 30-40% 现金"——本质上是对周期不确定性的防御
- "不与政策对着干"——Dalio 体系中的制度化表达

### 1.3 外部秩序大周期

**核心规律**：当崛起国实力接近守成国时，冲突概率急剧上升。

**典型模式：**
```
贸易摩擦 → 技术封锁 → 资本战 → 地缘角力 → 代理人战争 → 全面战争
```

**当前格局（Dalio 2022 判断）**：
- 美国处于帝国周期的顶部偏后阶段
- 中国处于快速上升阶段
- 中美冲突是结构性的，不以个人意志为转移
- 但全面战争并非必然

**投资含义**：
- 跨国配置需要考虑地缘风险
- 中美各自的"不可替代资产"值得重点关注
- 供应链安全 = 新的投资主题
- 货币多元化（不把所有资产放在单一法币体系）

**与段永平体系的交叉**：
- 段永平同时持有美股（苹果）和 A 股/港股（茅台、腾讯）——无意中实现了 Dalio 建议的跨国配置
- 英伟达的小仓位——在地缘风险中的"两边下注"思维
- "AI 确实会替代工作"——技术竞争是外部秩序周期的核心驱动力

**巴菲特日本商社投资的货币中性实践**（与 Dalio 跨国配置完美对照）：
- 巴菲特2020年开始投资日本五大商社（ITOCHU、Marubeni、Mitsubishi、Mitsui、Sumitomo）
- 用**日元借款**买日本股票 → 汇率风险对冲 = 货币中性
- 年分红收入$812M >> 日元债务利息$135M → 净正现金流
- 这不是"赌日元方向"，而是消除货币风险后纯粹押注企业价值
- **与 Dalio 的共同逻辑**：Dalio 建议"不要押注单一国家/货币"，巴菲特用日元负债+日元资产完美实现
- 详见 [[philosophy]] §5.9

## 二、18 个国家实力决定因素

Dalio 识别的衡量国家实力的 18 个维度，可用于判断一个国家在周期中的位置：

| 维度 | 简述 | 中国评估 | 美国评估 |
|------|------|----------|----------|
| 教育 | 教育质量和普及度 | 快速提升 | 依然领先但相对下降 |
| 竞争力 | 全球市场中的成本和创新 | 强势上升 | 相对下降 |
| 创新/技术 | 科技产出和研发投入 | 快速追赶 | 仍领先但差距缩小 |
| 经济产出 | GDP 和经济规模 | 接近或超越（PPP） | 绝对值仍领先 |
| 贸易 | 全球贸易份额 | 最大贸易国 | 相对下降 |
| 军事实力 | 军费和技术 | 快速现代化 | 全球领先 |
| 金融中心 | 资本市场深度和开放度 | 有限开放 | 全球核心 |
| 储备货币 | 货币的国际地位 | 人民币国际化起步 | 美元主导但份额下降 |
| 基础设施 | 物理和数字基建 | 世界领先 | 老化 |
| 法治 | 契约精神和产权保护 | 有中国特色 | 依然较强但有不确定性 |
| 成本优势 | 劳动力和生产成本 | 仍在但收窄 | 不具备 |
| 债务负担 | 政府/企业/居民债务 | 地方政府债务较高 | 联邦债务极高 |
| 人口结构 | 年龄结构和劳动力 | 老龄化挑战 | 移民缓解部分压力 |
| 贫富差距 | 收入和财富分配 | 扩大中 | 极化严重 |
| 内部冲突 | 政治和社会稳定性 | 相对稳定 | 高度极化 |
| 地缘地位 | 盟友和国际影响力 | 扩大中 | 仍最强但有摩擦 |
| 自然资源 | 能源和矿产 | 部分依赖进口 | 较丰富 |
| 自然灾害/气候 | 脆弱性 | 面临挑战 | 面临挑战 |

**投资使用方法**：不需要精确打分，而是判断大致趋势——上升、持平、还是下降。

## 三、从大周期角度思考投资（第七章要点）

### 3.1 历史回报规律

Dalio 研究了多个帝国的资产回报，发现：

- **持有股权的长期回报最高**——在几乎所有国家和时期
- **债券在稳定期回报尚可，在贬值期灾难性**
- **现金是长期最差的资产**——在法币体系下必然被稀释
- **黄金在混乱期表现最好**——但稳定期跑输股权

**与段永平的共鸣**：
- "我是一个满仓主义者"——Dalio 的数据支持这一判断
- 但 Dalio 更强调"哪个国家的股权"——段永平的无意识跨国配置恰好符合

### 3.2 十大投资原则（Dalio 版）

1. **理解你处于周期中的哪个位置**——大方向比个股选择更重要
2. **不要押注单一国家/货币**——分散是唯一的免费午餐
3. **在债务泡沫期减少风险敞口**——不要在山顶加仓
4. **持有硬资产对抗法币贬值**——优质股权、黄金、实物
5. **关注贫富差距和民粹主义指标**——它们是内部危机的前兆
6. **地缘冲突升级时增加防御**——不意味着清仓，而是调整比例
7. **不要假设"这次不一样"**——历史不会简单重复，但会押韵
8. **储备货币地位一旦丧失，很难恢复**——美元的长期风险
9. **技术领先是帝国兴衰的核心变量**——关注 AI/半导体竞争格局
10. **最危险的时刻是大家都觉得安全的时候**——反向指标

### 3.3 与段永平框架的互补关系

| 维度 | 段永平视角 | Dalio 视角 | 融合后 |
|------|-----------|-----------|--------|
| 选股 | "买股票就是买公司" | 不关心个股 | 用段永平方法选个股，用 Dalio 框架选国家/行业 |
| 估值 | 安全边际=理解深度 | 周期位置决定估值中枢 | 理解公司 + 理解它所处的大周期 |
| 仓位 | 50-60%股票，永不满仓 | 根据周期位置动态调整 | 基础仓位用段永平框架，极端周期用 Dalio 框架调整 |
| 持有期 | 长期持有，机会成本卖出 | 跟随大周期调整 | 优质个股长期持有，周期转向时整体仓位调整 |
| 风险 | 不懂不碰，不加杠杆 | 地缘风险、货币风险 | 个股风险用段永平，系统性风险用 Dalio |
| 中国 | "中国式价值投资"，政策敏感 | 中国处于上升周期，但面临挑战 | 用 Dalio 周期判断大方向，用段永平方法选中国公司 |
| 黄金 | 5-10% 配置 | 混乱期关键资产 | 基础配置 5-10%，周期风险升级时增加 |

## 四、Dalio 对中国的大周期分析

### 4.1 中国处于周期的哪个位置

Dalio 的核心判断（基于截至 2022 年的数据）：

- **经济**：按 PPP 计算已是最大经济体，按名义 GDP 接近美国
- **技术**：快速追赶，在 5G、电动车、AI 应用等领域领先或并跑
- **金融**：人民币国际化程度有限，资本市场尚未完全开放
- **军事**：快速现代化，但全球投射能力仍不及美国
- **内部**：中央集权高效，但面临地方债务、房地产、人口结构挑战
- **外部**：与美国的结构性竞争加剧，但全面冲突非必然

### 4.2 对中国投资者的具体含义

**利好因素（Dalio 框架支持做多中国优质资产）：**
- 上升周期国家的优质企业回报更佳
- 中国政府有强大的危机管理能力（基建、财政工具）
- A 股的波动性反而创造了超额收益机会
- 茅台等企业具有 Dalio 所说的"不可替代资产"特征

**风险因素（Dalio 框架提醒警惕）：**
- 地方政府债务和房地产调整是内部周期的风险点
- 中美对抗可能波及特定行业（半导体、互联网）
- 人口结构变化影响长期消费模式
- 法治和产权保护的确定性不如成熟市场

**与段永平的实践对比**：
- 段永平同时持有中美资产 = 对冲两国各自的周期风险
- 茅台持仓体现了"中国上升周期中的不可替代资产"逻辑
- 英伟达小仓位 = "技术竞争是核心变量"的直觉判断
- 腾讯回购注销 = Dalio 框架中"好公司用现金流回馈股东"的最佳实践

## 五、实操框架：段永平 + Dalio 双层决策模型

### 第一层：Dalio 宏观周期定位（每半年检视一次）

回答以下问题，判断当前周期位置：

- [ ] 全球债务/GDP 是否处于历史高位？（是 → 警惕泡沫期）
- [ ] 主要国家贫富差距是否在扩大？（是 → 内部风险上升）
- [ ] 中美关系是否在恶化趋势中？（是 → 增加防御）
- [ ] 央行是否在大规模印钞？（是 → 持有硬资产，减少现金）
- [ ] 技术竞争格局是否有结构性变化？（是 → 调整行业配置）
- [ ] 全球储备货币格局是否有变化信号？（是 → 考虑货币多元化）

**判断结果 → 影响总仓位和大类配置：**

| 周期判断 | 股票仓位 | 黄金 | 现金 |
|----------|----------|------|------|
| 繁荣稳定期 | 60% | 5% | 35% |
| 泡沫预警期 | 45% | 10% | 45% |
| 危机期 | 35% | 15% | 50% |
| 重建机遇期 | 55% | 5% | 40% |

### 第二层：段永平个股分析（对每一笔投资）

在 Dalio 宏观框架给定的仓位空间内，用段永平五维框架选具体公司：

1. 存续判断 → 10 年后还在吗？
2. 生意模式 → 是不是好生意？
3. 核心竞争力 → 护城河在哪里？
4. 风险规避 → 哪里可能出问题？
5. 估值研判 → 现在贵不贵？

### 双层决策示例

**案例：2025 年持有茅台**

| 层级 | 分析 | 结论 |
|------|------|------|
| Dalio 宏观 | 中国处于上升期但面临房地产和人口挑战；全球处于债务泡沫后期；货币贬值趋势 | 中国优质资产值得持有，总仓位适度 |
| 段永平个股 | 茅台是不可替代的轻资产高分红企业，护城河极深，管理层稳定 | 继续持有，分红再投入 |
| 融合决策 | 宏观支持持有中国核心资产，个股分析确认茅台是最优标的 | 维持茅台为核心持仓（但不超过 40%），保留 30%+ 现金应对周期风险 |

**案例：考虑买入英伟达**

| 层级 | 分析 | 结论 |
|------|------|------|
| Dalio 宏观 | AI 是大国技术竞争核心变量；半导体是地缘博弈焦点 | AI 敞口有必要，但地缘风险高 |
| 段永平个股 | 不完全懂半导体，但黄仁勋长期可信，CUDA 生态壁垒强 | 小仓位试探，"没有到投苹果那个程度" |
| 融合决策 | 宏观方向确定但个股理解深度不够 | 小仓位（<5%），用 Dalio 框架确定方向，用段永平框架控制仓位 |

## 六、Dalio 核心语录

| 语录 | 投资含义 |
|------|----------|
| "不研究历史，就无法理解现在" | 投资决策需要历史视角，不能只看当下数据 |
| "未来是过去的函数" | 周期会重复，虽然不会简单重复 |
| "最危险的时刻是大家都觉得安全的时候" | 市场共识最一致时，风险最大 |
| "储备货币的特权是暂时的" | 不要假设美元永远安全 |
| "内部冲突的根源是财富差距" | 关注贫富分化指标作为预警信号 |
| "谁赢谁输取决于制度效能" | 投资制度高效的国家/公司 |
| "战争是昂贵的，即使是赢的一方" | 地缘冲突中减少风险敞口 |
